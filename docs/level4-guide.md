# Level 4｜外部刺激と適応（スクワット） 使い方ガイド

> **本機能は、制御の仮説ごとの予測を示す概念モデルです。人の身体、身体感覚、膝サポーターの効果、特定の研究結果を再現したものではありません。**

ツールは **https://ft-1-six.vercel.app/** の「Level 4｜外部刺激と適応（スクワット）」タブにあります。
このガイドは専門知識のない人向けです。7つの手順それぞれで「何をすれば、何が分かるか」を説明します。

---

## このタブで確かめたいこと

```
外部刺激  →  感覚の変化  →  ？？？  →  動作の維持
```

膝に刺激（サポーターのような支え、感じ方のずれ、疲れなど）をかけると、スクワットの動きは保たれるのか。保たれるとしたら、内側では何が変わっているのか。
「？？？」の部分に入る **制御の仮説** を3つ用意し、それぞれの仮説のもとでどんな変化が予測されるかを比べます。

答えを出す道具ではなく、**将来、人の実験データと照らし合わせるための「基準の予測」を作る道具**です。

### 登場するもの

| 用語 | 意味 |
| --- | --- |
| 被験者モデル | 横から見た棒人間。すね・もも・胴体の3本の棒と、足首・膝・股の3つの関節でできている（体重 60 kg の**概算値**） |
| 重心（⊕） | 体全体の重さの中心。スクワットでは、これを 25 cm 下げて戻す |
| 支持基底面（緑の帯） | かかとから爪先まで。重心の真下がこの中にあればバランスが保てている |
| 同時収縮 | 曲げる筋と伸ばす筋を同時に力ませること。関節が硬くなり揺れに強くなるが、筋が疲れやすい |
| 試行 | スクワット1回 |

---

## 手順1　被験者モデルを確認する

**分かること**：刺激がないとき、モデルがどうスクワットするか。

**やること**
1. 棒人間の動きを見る（▶ 再生 / ⏸ 一時停止、速度の切り替え、横長のスライダーで好きな時刻に止められる）。
2. 「体幹の前傾の好み」のスライダーを動かす。

**見るところ**
- 重心（⊕）が点線の目標どおりに下がって戻ること。
- 前傾の好みを変えると、**重心の動きは同じまま、胴体の倒れ方と膝の曲がり方が変わる**こと（同じ結果を、違う関節の使い方で実現できる）。
- 関節の円の大きさ＝その関節が出している力（トルク）。一番深いところで膝の円が大きくなる。
- 右の表で、モデルの寸法・質量が**概算値**であることを確認する。

---

## 手順2　外部刺激を選ぶ

**分かること**：刺激をかけたスクワット1回で、何が変わり、何が変わらないか。

**やること**
1. 左側で刺激を選ぶ（複数選べる）。

   | 種類 | 刺激 | イメージ |
   | --- | --- | --- |
   | 機械的 | 膝の可動域の制限 | 膝が一定以上曲がらない |
   | 機械的 | 膝の受動的な支え（ばね） | 膝が曲がるほど、伸ばす向きに押し返される |
   | 感覚的 | 膝角度の知覚のずれ | 実際より膝が曲がっていると感じる（例：5°） |
   | 感覚的 | 膝角度の知覚の精度 | 感じ方が鋭くなる／鈍くなる |
   | 身体の状態 | 疲労 | 試行を重ねるたびに、膝を伸ばす筋が弱くなる |

2. 必要なら「同時収縮の大きさ」を変える。
3. 右側で、刺激なし（灰）と刺激あり（青）の棒人間を重ねて見る。

**見るところ**
- 表の「差」の列（緑＝良くなった、赤＝悪くなった、≈ 同じ）。
- 例：**膝のばね**では、膝の角度は「≈ 同じ」なのに、「膝の伸ばす筋の力」だけが大きく減る。**外から見ても分からない変化**の例。
- 例：**知覚のずれ**では、オレンジの点線（モデルが感じていた膝角度）と青の線（実際の膝角度）がずれ、重心の深さが変わる。
- 膝への刺激を選ぶと、膝にオレンジの帯（サポーター）が描かれる。サポーターが実際にどの作用を持つかは、このモデルでは決めていません。「機械的な作用だけ」「感覚的な作用だけ」「両方」を組み合わせて比べられます。

## 手順3　制御の仮説を選ぶ

**分かること**：刺激に対して、モデルがどんな規則で動きを直していくか。

| 仮説 | 一言で | 調整できる値 |
| --- | --- | --- |
| 仮説1：誤差だけを直す（記憶なし） | その回の中で、感じた重心のずれだけを直す。前の回のことは覚えていない | なし |
| 仮説2：経験から少しずつ直す（記憶あり） | 毎回、動き方の設定を少し変えて試し、楽になった向きへ少しずつ変える | 保持率（どれだけ覚えているか）、学習率（どれだけ速く変えるか）、速い成分と遅い成分の2つを持たせるか |
| 仮説3：感覚の基準を直す | 「自分の膝の感じ方がずれているかも」と推定し、外の手がかり（目で見た重心の位置）で補正する | 学習率、外の手がかりを使うか、手がかりのノイズ |

**やること**：カードをクリックして仮説を選び、必要なら値を調整する。

## 手順4　4期間のプロトコルを実行する

**分かること**：刺激をかける前・かけている間・外した後・もう一度かけたときの、試行ごとの記録。

**やること**
1. 各期間の試行数を確認する（初期値：習得期 100 → 刺激期 100 → 解除期 50 → 再刺激期 100）。
2. 「プロトコルを一括実行」を押す（1秒程度）。

**見るところ**
- 期間ごとの成功数（失敗した試行も消さずに残します）。
- 下のグラフ：背景が白＝習得期、赤＝刺激がかかっている期間、青＝解除期。
- 例：知覚のずれ＋仮説3では、刺激が入った瞬間に深さの誤差が下にずれ、だんだん0に戻り、刺激を外すと**逆向き**に飛び出して、また戻っていく。

> 同じ乱数シード・同じ設定なら、何度実行しても同じ結果になります。

---

## 手順5　学習曲線と後効果を見る

**分かること**：この仮説のもとで、試行を重ねると何がどう変わり、刺激を外した後に何が残るか。

**やること**
1. 上のボタンで、グラフにしたい量を選ぶ（重心の誤差、コスト、関節ごとの寄与率、同時収縮など）。
2. 平滑化のスライダーで、細かな揺れをならす。

**見るところ**
- **後効果の表**：刺激を外した直後（解除期の最初の5回）が、刺激をかける前（習得期の最後の20回）とどれだけ違うか。
  - 「あり／なし」：普段のばらつきの2倍を超えていれば「あり」。
  - 「向き」：刺激を入れた直後の変化と**反対向き**なら、刺激に合わせて直していたものが残っている印。
- **再刺激での速さ**：1回目と2回目で、半分まで直るのに何回かかったか。比が1未満なら2回目の方が速い。
- **R の棒グラフ**：重心を保ったまま関節の使い方がどれだけばらついているか（Level 3 と同じ計算）。
- 一番下で、代表的な試行（刺激の前・直後・最後・解除直後）の動きを重ねて再生できる。

## 手順6　観測者ごとの見え方を見る

**分かること**：同じ変化が、どの計測手段なら外から検出できるか。

| 観測者 | 見ているもの | 人の計測でいうと |
| --- | --- | --- |
| 結果の観測者 | 重心の深さ、バランスの成否、1回の時間 | 目視・映像 |
| 動きの観測者 | 関節の角度、重心の位置 | 映像解析・IMU（動きのセンサー） |
| 内部の観測者 | 関節の力、筋の力、同時収縮 | 床反力・筋電 |

**やること**
1. 観測者ごとの測定ノイズ（計測の粗さ）を必要に応じて変える。
2. 「何倍で変化とみなすか」「何回続いたら見えたとするか」を確認する（初期値：2倍、3回）。

**見るところ**
- **見え方の表**：縦が観測者、横が試行番号。色の付いたところが「変化が見えた」試行。
- **紫の帯**：「結果の観測者には見えないが、内部の観測者には見える」区間。外から見て同じでも、内側では違っている区間です。
- 下の表：変化に気づくまでに何回かかったか。「この観測手段では検出できない」は、その期間中に一度も気づけなかったという意味。

---

## 手順7　3つの仮説を比べる

**分かること**：同じ刺激に対して、仮説ごとに予測がどう違うか。

**やること**：「3つの仮説をまとめて実行」を押す（2秒程度）。刺激は手順2、試行数とシードは手順4、仮説2・3の調整値は手順3の値を使います。

**見るところ**
- 学習曲線の重ね描き（灰＝仮説1、青＝仮説2、赤＝仮説3）。
- 後効果の表：どの仮説に、どちら向きの後効果が出るか。
- 観測者の表：どの仮説なら、どの観測者が何回目で変化に気づくか。

**例：膝角度の知覚のずれ（+5°）**
- 仮説1：直さない。刺激を外すとすぐ元に戻る（後効果なし）。
- 仮説2：感じている情報では誤差が見えないため、ほとんど直さない。
- 仮説3：だんだん直し、外した直後に逆向きの誤差が出る（後効果あり）。

→ 人の実験で「刺激を外した直後に逆向きの誤差が出るか」を測れば、どの仮説が近いかの手がかりになる、ということが分かります。

## よくある質問

**Q. グラフの結果は人のスクワットの結果ですか？**
A. いいえ。仕込んだ規則（制御の仮説）から機械的に出てくる予測です。人がこう適応することを示すものではありません。

**Q. 「この観測手段では検出できない」とは？**
A. 設定した測定ノイズと判定の決まりのもとでは、その期間中に変化を見つけられなかった、という意味です。ノイズを小さくすると見つかることがあります。

**Q. 刺激がないのに「変化が見えた」となる試行があります。**
A. 測定ノイズによる偶然の超過です（仮説1・3で約1%）。仮説2は毎回少しずつ設定を試し続けるため、刺激がなくても本当に少しずつ変わり続けます。

**Q. 結果が毎回同じなのはなぜ？**
A. 乱数のシードを固定しているからです。シードを変えると、ノイズの入り方が変わった別の実行になります。
