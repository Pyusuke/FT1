# 次の拡張候補

> 本ツールは研究仮説を理解するための概念モデルです。人の身体や特定の研究結果を再現したものではありません。

[findings.md](findings.md) で分かった限界に対応する順に並べています。

## 1. 冗長性を増やす（Phase 2・4 の限界への対応）

- **3D化**：肩3自由度・肘1・前腕回旋1・手首2 の 7 自由度アームにすると、手先位置だけでも冗長性が 4 次元になり、「肘を上げる／下げる」のような人に近い戦略の違いを出せる。描画は Three.js（今回は Canvas 2D のみ）か、2D 投影の複数ビュー。
- **体幹・脚**を加え、全身の重心やバランスを拘束に加える（「手先は同じで、足の踏ん張りが違う」）。
- 平面のままでも、手先の速度や力の方向をタスクに加えて、冗長性の使い道を増やす。

## 2. 物理エンジンの導入（Phase 3〜5 の限界への対応）

- **MuJoCo（mujoco-wasm）や Rapier などをブラウザで動かす**：順動力学・接触・摩擦を正しく扱い、外乱からの回復や荷物への適応を「選び直し」ではなく連続的な制御として評価する。
- **トルク制御・インピーダンス制御**：IK で関節角を決めるのではなく、計算トルク法やインピーダンス制御で追従させ、剛性・減衰を戦略の一部にする（陶芸カードをより自然に表現できる）。
- **時間最適化・軌道最適化**：一様な時間伸縮ではなく、トルク制限下での時間最適な軌道（例：直接コロケーション、iLQR）を解き、野球カード（運動連鎖による加速）の効果を本当に検証する。
- **筋骨格モデル**（MyoSuite など）との比較：関節トルクではなく筋で駆動したとき、配分の傾向が変わるか。

## 3. 接触の扱いの高度化（Phase 5 の限界への対応）

- 準静的な直列ばねではなく、**接触の動力学**（跳ね・はりつき滑り・クーロン摩擦の正確な扱い）。
- 面の形状（曲面・凹凸の分布）、材料の粘弾性、工具の形状（筆・こて）のモデル化。
- 接触力の**力制御**ループと、手首の姿勢の自由度の扱い（法線に合わせる／あえて傾ける）。

## 4. 人の動作データの読み込み

- モーションキャプチャ（BVH・C3D など）を読み込み、平面に射影して関節角の時系列と手先軌道を取り出す。
- 同じ手先軌道を A〜E の戦略で再計算し、**人のデータと IK・コスト最適化の結果の違い**を同じ指標で比較する（「既存の単純な手法で説明できる部分」と「できない部分」を切り分ける）。
- 逆最適化（inverse optimal control）：人のデータを最もよく説明するコストの重み wᵢ を推定する。ここで初めて「データから推定する」処理が入るが、その場合も推定であることを明示する。

## 5. 探索・最適化の改善

- ランダム探索（200 / 120 候補）を CMA-ES やベイズ最適化に置き換え、Phase 5 で見えた「探索不足で単独カードが不利になる」効果を切り分ける（同じ計算予算で比べる）。
- 多目的最適化（NSGA-II など）でパレート前線全体を求め、プリセットごとの点ではなく前線の形の変化を見る。
- カードの重みそのものを探索変数にし、カード同士の衝突（例：書道と野球）を可視化する。

## 6. ツールとしての改善

- 実験条件（動作・コスト・条件・カード・シード）を JSON で保存・読み込みし、結果を CSV で書き出す。
- 複数のシードで繰り返し、結果のばらつき（BEST の入れ替わりの安定性など）を表示する。
- 正規化の方法（固定基準値／候補集合の中央値／順位）を切り替えて、結論が正規化に依存するかを確かめる。
