# Level 3「運動戦略の発見」で分かったこと

> 本機能はシミュレーション上の統計的な傾向を示す概念モデルです。人の身体や身体感覚、特定の研究結果を再現したものではありません。ばらつきの傾向や関連は、因果関係を示しません。

問い：**結果が同じになる多数の試行から、何が守られていて、何が自由に使われているかを、データだけで見分けられるか。**

数値は既定の設定（動作：加算 Reach + Wave、目的：最速搬送、300 試行、シード 1、全条件をばらつかせる）での計算結果です。

---

## 1. 既存の手法（逆運動学・ばらつきの分解・分類）だけで分かったこと

### 3A：目的プリセット → 重み
- 8つのプリセットから、2段階の対応表（要求 → 重み）で重みを決めると、BEST の戦略は順に切り替えたとき4回入れ替わった（A → D → A → D → A）。
- ただし入れ替わるのはほぼ A と D の2択。A〜D の J の差は 0.01 程度しかない（Level 2 と同じ限界）。

### 3B-2：ばらつきの分解（R）
| 条件 | R（時間全体） | 解釈 |
| --- | --- | --- |
| 通常（手先の位置だけを指定） | **57.9** | 手先は守られ、関節は自由に使われている傾向 |
| 冗長性なし（手先の向きも指定） | **0.57** | 守られている様子はない（1 前後） |
| 検証：ヌル空間だけにばらつき | 12166 | 正しく「> 1」 |
| 検証：手先方向だけにばらつき | 0.01 | 正しく「< 1」 |
| 検証：等方的なばらつき | 1.00 | 正しく「≈ 1」 |

- 分解の手法そのものは、正解を仕込んだデータで正しく働いた。
- 冗長性があれば R ≫ 1、なければ R ≲ 1 という、教科書的な結果はそのまま出た。

### 3B-3：守られている変数・自由な変数
- **守られている可能性**：手先位置 x・y（ばらつき 0.015・0.026）、肩の寄与率（0.067）
- **自由な可能性**：手先の向き（0.95）、手首角（0.99）、肘角（0.71）、関節トルク3つ（0.49〜0.73）、手首の寄与率（0.67）
- 検証データ（手首角を固定し、肩と肘を自由にしたもの）では、「手首は守られている、肩と肘は自由」と正しく判定できた。

### 3B-4：戦略のまとまり
- 推奨のまとまりの数はシルエット係数で決まり、k = 5（300 試行）。ただし係数は 0.36〜0.41 と、どの k でも大差なかった。
- 戦略 C が 92% を占めるまとまりなど、仕込んだ戦略 A〜E の違いがほぼそのまま分類に現れた。

## 2. 分からなかったこと、結果が不自然だったこと

1. **R > 1 は「制御の作り」から自動的に出てくる。**
   センサーノイズだけをばらつかせると R ≈ 0 になった。ノイズは手先位置のフィードバックを通じて入るので、手先を動かす方向のばらつきしか生まないためである。
   R > 1 になるのは、初期姿勢や戦略の違いでできたヌル空間方向のずれを、制御が直さずに放置するからである。
   つまり「手先を守っている」ように見えるのは、手先の誤差だけを直すという IK の構造の結果で、何かを見つけ出したり学んだりした結果ではない。

2. **全試行をまとめた R は粗い近似。**
   戦略ごとに計算した R は 29〜890 と、桁で違った。姿勢の大きく異なる試行を、1つの平均姿勢での直線近似で分解しているためである。

3. **肘の可動制限の影響は小さかった。**
   - R は約 1.2 倍変わった。300 試行では偶然の範囲（p ≈ 0.2）だったが、1000 試行では偶然とは考えにくかった（p = 0.005）。
   - まとまりの分布の違いは、k と乱数シードによって p ≈ 0.04〜1.0 とばらつき、多くは偶然でも起こる程度だった。
   - 多くの戦略で、肘はもともと制限後の範囲の中で動いている。寄与率やトルク配分は、可動域の端に近づいたときにしか変わらない。
   - 完了条件の「まとまりの分布が変わる」ははっきりとは満たせなかった。条件を強めて合わせることはしていない。

4. **荷重でまとまりの分布が大きく変わったのは「選別」の結果。**
   重い荷重ではまとまりの分布が変わった（p = 0.002）。しかしこれは、速い戦略が重い荷物でトルク超過になって失敗し、成功した試行から抜け落ちたためである。戦略が荷重に合わせて変わったわけではない。成功した試行だけを分析する手法には、この偏りがつきまとう。

5. **「手先が守られている」は課題の定義から当然。**
   手先が目標をなぞる課題なので、手先位置が守られているという判定はほぼ自明である。データから新しく見えたと言えるのは、「肩の寄与率がそろっている」「手首角は自由に使われている」といった、内部の変数についての傾向だけである。

6. **トルクの推定には平滑化が必要だった。**
   ノイズや外乱による細かな揺れを差分で増幅すると、見かけのトルクが上限の4倍を超えた。そのため、速度・トルクは平滑化した関節角から推定した。トルク超過による失敗は、この推定値での判定である。

7. **閾値は設計者の目安。**
   R の閾値（2・0.5）と、変数のばらつきの閾値（0.15・0.35）は目安であり、統計的な検定ではない。どの変数が「守られている」とされるかは、この線の引き方で変わる。

## 3. 人の動作データがないと答えられない問い

| 問い | 必要なデータ |
| --- | --- |
| 人の動作でも R > 1 になるか。なるとしたら、どの時期（学習の初期・熟練後）か | 同じ課題を何度も繰り返したときの関節角度（モーションキャプチャ） |
| 人の R > 1 は「誤差だけを直す制御」の結果か、それとも積極的に関節を自由に使っている結果か | 関節角度に加え、外乱を与えたときの応答 |
| 人では、関節側のノイズ（運動ノイズ）と感覚側のノイズのどちらが、ばらつきの主な原因か | 筋電（EMG）と関節角度の同時計測 |
| 人はばらつきを「自由に使っている」と感じているか、意識していないか | 主観的な報告（身体感覚の質問紙、インタビュー） |
| 熟練者と初心者で、守られている変数は違うか | 熟練度の異なる人の動作データ |
| まとまり（Cluster）は、人が自分の動きを説明するときの分け方と一致するか | 動作データと、本人による動きの説明や分類 |
| 疲労・痛み・けがの後に、配分は連続的に変わるか、それとも別のまとまりへ切り替わるか | 長時間の課題や、けがの前後の動作データ |

## 4. まとめ

- 「同じ結果を、違う身体の使い方で実現している」という傾向は、ばらつきの分解で**データから見分けられた**。手法は、正解入りのデータで正しく働くことも確かめた。
- ただしこのモデルでは、その傾向は **IK の構造と、条件をどう振ったかでほぼ決まっている**。見分けたものは、私たちが仕込んだものを読み戻している面が大きい。
- 人の運動で同じ分析が意味を持つかどうかは、**人のデータでしか確かめられない**。このツールは、分析手法が正しく働くかを確かめる道具、分析の限界を知る道具として使うのが適切である。
