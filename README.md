# Motor Strategy Playground（運動戦略プレイグラウンド）

> **本ツールは研究仮説を理解するための概念モデルです。人の身体や特定の研究結果を再現したものではありません。**

次の5つの研究仮説を、ブラウザ上で触りながら数値で確かめるための検証用プロトタイプです。製品ではありません。

1. 基本動作（Motion Primitive）を合成すると、新しい動作を作れる
2. 同じ手先の結果を、異なる関節配分（運動戦略）でも実現できる（冗長性）
3. コストの重みを変えると、選ばれる運動戦略が変わる
4. 外部条件が変わると、内部の戦略は変わるが、手先の結果は維持される
5. 異なる領域の「運動知」を組み合わせると、どれとも違う動作が生成される

それぞれについて「成り立つか」「既存の単純な手法（IK・コスト関数・探索）だけで再現できてしまうか」を見極めるのが目的です。
すべての結果は **逆運動学・コスト関数・ランダム探索による計算** であり、学習（機械学習）は一切使っていません。

## すぐに使う

**https://ft-1-six.vercel.app/** をブラウザで開くだけで使えます（インストール不要。計算はすべてブラウザ内で行います）。

画面は3つのタブに分かれています。

| タブ | 内容 | ガイド | 分かったこと |
| --- | --- | --- | --- |
| Level 1・2｜動作合成・コスト最適化 | 腕のアームで、動作の合成・冗長性・コストによる選択・外部条件・運動知カード | [manual.md](docs/manual.md) | [findings.md](docs/findings.md) |
| Level 3｜戦略発見 | 多数の試行から、守られている量・自由に使われている量をデータで見分ける | [level3-guide.md](docs/level3-guide.md) | [findings-level3.md](docs/findings-level3.md) |
| Level 4｜外部刺激と適応（スクワット） | 脚のモデルに膝への刺激をかけ、制御の仮説ごとに適応・後効果・観測者ごとの見え方を予測する | [level4-guide.md](docs/level4-guide.md) | [findings-level4.md](docs/findings-level4.md) |

はじめて使う方は、まず [使い方ガイド（docs/manual.md）](docs/manual.md) を読んでください（印刷・配布用の [PDF 版](docs/manual.pdf) もあります）。画面の見方と、5つの仮説を確かめる手順を画像付きで説明しています。

## 画面構成

| 位置 | 内容 |
| --- | --- |
| 最上部 | 注記（常時表示） |
| 上段左 | 基本動作の選択・パラメータ・合成方法（単体／加算／連結／ブレンド） |
| 上段中央 | アームのアニメーション（再生・一時停止・速度・軌跡、「戦略を重ねて再生」） |
| 上段右 | コストの重みスライダー・プリセット |
| 中段左 | 戦略の比較表（正規化指標・J・BEST）。行クリックでその戦略を再生 |
| 中段右 | 関節角度の時系列・パレート図 |
| 下段 | 外部条件（Phase 4）と前後比較 |
| 最下段 | 運動知カード（Phase 5） |

各パネルの「i」ボタンから、使っている計算式を参照できます（`src/ui/formulas.ts`）。
可動範囲を超える解・到達できない目標・トルク超過・接触中の滑りは、値を黙って補正せずに警告として表示します。

## モデルの要点

- 平面3リンクアーム（L = 0.40 / 0.35 / 0.15 m）、重力は −y。リンクは一様棒（線密度 5 kg/m）。
- 可動範囲：肩 −60°〜150°、肘 −150°〜0°、手首 −90°〜90°。最大角速度 [2.5, 3.5, 5.0] rad/s、最大トルク [60, 40, 12] Nm。
- IK：`dq = W⁻¹Jᵀ(JW⁻¹Jᵀ + λ²I)⁻¹dx + (I − J⁺J)·k·(q_pref − q)`。可動範囲の端に近い関節は重みを大きくする。
- 所要時間は「各関節の最大角速度を守る最短時間」（一様な時間伸縮）。トルクは `M(q)q̈ + g(q) − JᵀF`（コリオリ項は省略）。
- 乱数はすべてシード固定（E の探索：seed 12345・200 候補、Phase 5：seed 2024・120 候補）。同じ条件なら同じ結果になります。

## テスト

`npm test` で各フェーズの完了条件を検証します。

| ファイル | 内容 |
| --- | --- |
| `tests/kinematics.test.ts` | FK の既知角度、ヤコビアン＝数値微分、IK→FK の誤差 1 mm 未満 |
| `tests/composition.test.ts` | Reach+Wave の直交変位、連結のつなぎ目で速度連続、ブレンドの端点 |
| `tests/strategies.test.ts` | A〜D の手先誤差 RMS < 2 mm、関節軌道の差 > 0.1 rad、決定性 |
| `tests/cost.test.ts` | プリセットで BEST が 2 回以上入れ替わる、J(E) ≤ min J(A〜D)、パレート点の非支配性 |
| `tests/conditions.test.ts` | 条件下で手先が維持され配分が変わる、肩の故障は「維持できない」 |
| `tests/skills.test.ts` | 1枚と複数枚で軌道と J が異なる、改善と悪化の両方が出る |

各フェーズで分かったことは [docs/findings.md](docs/findings.md)、拡張候補は [docs/next.md](docs/next.md) にまとめています。
